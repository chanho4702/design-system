# @chanho/org-admin

## 0.3.2

### Patch Changes

- 표의 사람 이름 칸(사용자·승인 대기·팀 구성원·전역 역할 대상)은 최소 5em을 한 줄로 지키고 어절 단위로만 줄바꿈 —
  390px에서 "김/찬/호"처럼 글자마다 끊기던 문제. 이메일·받는 주소 칸은 12em까지 한 줄, 더 긴 주소만 아무 데서나 끊는다.
  표가 화면보다 넓으면 표 안에서 가로로 스크롤된다(react 0.13.1 Table 셀 규칙과 함께).

## 0.3.1

### Patch Changes

- 로딩 스피너를 스켈레톤으로 교체 — 목록(`DataSection`)은 표 모양 스켈레톤, 사용자 상세·이력·구성원 검색·승인 대기 게이트도 같은 방식.
  로딩이 끝나도 자리가 크게 바뀌지 않는다. 스크린리더 문구("불러오는 중" 등)는 그대로다.
- 팀 목록 항목을 사이드바 항목 모양으로(왼쪽 정렬·긴 이름 말줄임·선택은 selected 배경, `aria-pressed`). 가운데 정렬 버튼 + 이름이 칸 밖으로 넘치던 문제.
- 팀 화면 2단 그리드 오른쪽 열 `minmax(0, 1fr)` — 긴 이메일이 그리드를 밀어 "팀 만들기" 카드가 표와 겹치던 문제(카드 넘침은 react 0.13.0 `Card` 수정과 함께 해소).
- peer 최소 버전: `@chanho/react` >=0.13.0(Skeleton·Card 수정), `@chanho/tokens` >=0.6.0(스켈레톤 색).
